## Datasets

### Network Flow

The network flow binary generates a network to use based on user input.

### Greedy

The greedy algorithm binary takes a Portable Game Notation (PGN) file as input. PGN files are used to record Chess matches. There are a wide variety of datasets available online. The provided `sample.pgn` file is an export of [British Chess Championships 2024: Championship](https://s1.chess-results.com/tnr969132.aspx?lan=1&art=4&turdet=YES&flag=30&SNode=S0).
